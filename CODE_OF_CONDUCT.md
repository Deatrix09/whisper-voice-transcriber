# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## Our pledge

We as members, contributors and maintainers pledge to make participation in this
project a harassment-free experience for everyone, regardless of age, body size,
visible or invisible disability, ethnicity, sex characteristics, gender identity and
expression, level of experience, education, socio-economic status, nationality,
personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive, especially in code review.
- Assume good intent and ask clarifying questions.
- Accept feedback gracefully and focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults, or personal or political attacks.
- Sexualized language or imagery and unwelcome advances.
- Publishing others' private information without explicit permission.
- Other conduct that could reasonably be considered inappropriate in a professional setting.

## Enforcement

The maintainer ([@Deatrix09](https://github.com/Deatrix09)) is responsible for
clarifying and enforcing these standards and may remove, edit or reject comments,
commits, code, issues and other contributions that do not align with this Code of
Conduct, and may temporarily or permanently ban contributors for behaviour they deem
inappropriate.

Report incidents privately to the maintainer through a
[private security advisory](https://github.com/Deatrix09/whisper-voice-transcriber/security/advisories/new)
(mark it as a Code of Conduct report) or via the contact on the maintainer's GitHub profile.
All reports will be reviewed promptly and handled confidentially.

The full text of the Contributor Covenant 2.1, including the enforcement guidelines,
applies and is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
